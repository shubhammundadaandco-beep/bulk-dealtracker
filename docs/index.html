Smart Money Score – partial (deal-data only)

This score is intentionally partial. It only scores the two components this dataset can support – Deal Activity and Accumulation Pattern – from actual bulk/block deal rows in the selected range, excluding round-trips. Investor Quality, Fundamental, Technical, Valuation and Risk components require data sources (investor classification, financials, price/technical feeds) not present in this dataset, and are shown as Insufficient data rather than estimated. Max possible score shown is 35/35 (Deal Activity 20 + Accumulation 15), not 100 – treat this as a partial signal, not a full Smart Money Score. Click any row to see the exact inputs used.
